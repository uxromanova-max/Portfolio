# Как редактировать контент

Три файла в этой папке — `brand.json`, `product.json`, `assistant.json` — это весь текст и все пути к картинкам для трёх версий сайта. Код и вёрстка их не касаются: меняешь значение в файле → сайт обновляется, ничего в компонентах трогать не нужно.

Все три файла имеют **одинаковую форму** (одинаковые ключи/поля), просто с разными значениями — так что если один раз разобралась в `brand.json`, в двух других всё узнаваемо.

## Как править текст

Открой нужный файл (например `brand.json`) в любом текстовом редакторе (подойдёт даже VS Code, Notepad, или прямо GitHub в браузере — кнопка карандаша на файле). Найди нужный кусок текста как значение после двоеточия, в кавычках, и поменяй его. Например:

```json
"headline": "Ready when you are."
```

Меняешь только то, что внутри кавычек:

```json
"headline": "Hire the work. The title's the only thing missing."
```

Ничего до или после кавычек трогать не нужно — запятые, скобки `{ }` и `[ ]` должны остаться на месте, иначе файл перестанет читаться.

## Разделы в каждом файле

- `hero` — первый экран (заголовок, подзаголовок, кнопка, фото)
- `whyMe` — блок "почему я, даже без тайтла"
- `capabilityMap` — сетка компетенций
- `caseStudies.items` — кейсы; каждый кейс — отдельный блок `{ ... }` в списке `[ ]`. Кейсов может быть разное количество в разных версиях — просто добавь блок `{ ... }` (скопируй существующий и измени) или удали ненужный.
- `skillsTools` — навыки и инструменты по уровням
- `aiSystems` — блок про AI
- `cta` — финальный блок с кнопками

## Как менять картинки

1. Файл картинки кладёшь в папку `public/images/<версия>/`, например `public/images/brand/hero.jpg`.
2. В `content/brand.json` путь к ней уже указан как `"photo": "/images/brand/hero.jpg"` — если положила файл с тем же именем в ту же папку, менять сам content-файл не нужно, картинка обновится автоматически.
3. Если имя файла другое — поменяй путь в JSON на новое имя.

Рекомендуемое именование, чтобы не путаться:
```
public/images/brand/hero.jpg
public/images/brand/case-ora-1.jpg
public/images/brand/case-ora-2.jpg
public/images/product/hero.jpg
public/images/assistant/hero.jpg
```

## Важно про product.json и assistant.json

Эти два файла пока **черновик-каркас** — та же структура, что у `brand.json`, но вместо реального текста везде стоит `TODO`. Их можно смело переписывать при подготовке этих версий: структуру (ключи) лучше не менять, чтобы не сломать компоненты, а вот все значения-`TODO` — под замену.

## Если что-то сломалось

Если после правки сайт перестал собираться — почти всегда дело в пропущенной или лишней запятой/кавычке в JSON. Можно проверить файл на валидность бесплатно на jsonlint.com (вставить содержимое файла) — он покажет точную строку с ошибкой. Либо просто попроси Клод Код починить конкретный файл.
